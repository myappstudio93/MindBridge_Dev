One primary action

Every screen has exactly one obvious next step. Users arrive tired, anxious, or mid-crisis — a busy screen is a barrier, not a feature.

Crisis is never buried

The escalation path gets its own visual register (red, serif empathy line, single button) so it never reads like a rejected form validation.

Calm, not clinical

Warm paper tones and a serif voice for emotional moments — deliberately not the pastel-gradient meditation-app look competitors default to.
